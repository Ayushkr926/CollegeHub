# College Campus Engagement App

## 1. Project Overview
This app is a College/University campus engagement platform built with Flutter. It helps students, clubs, and organisers stay connected with college activities, events, notices, requests, and profiles in one place.

The project is designed to simplify communication and reduce information gaps between students and campus organisations.

## 2. What This Project Is For
This project is created for:
- Students who want to discover campus events, notices, and clubs
- Club or event organisers who want to publish events and manage registrations
- College administrators and organisers who need a simple way to approve requests and manage participation
- Institutions that want a digital platform instead of manual notice sharing and scattered communication

## 3. Problem This Project Solves
Before this app, campus communication often happens through:
- WhatsApp groups or manual announcements
- Printed notices and posters
- Duplicated event information on different channels
- Slow club member approval and event registration processes
- No central place to track student requests, club membership, or event activity

This app solves these issues by providing a single digital platform for:
- event discovery and registration
- club joining and approval
- notice publishing and reading
- profile updates for students and organisers
- organised campus communication

## 4. Main Features of the App

### 4.1 Onboarding and Authentication
- Splash screen and onboarding flow
- Welcome screen
- Student and club registration
- Login and role selection
- Forgot password flow
- Email verification / registration success flow

### 4.2 Student and Organiser Profiles
- Student profile screen
- Club profile screen
- Edit profile functionality
- Local storage support for user data
- Role-based profile management

### 4.3 Event Management
- View all events on the home screen
- Search and filter events
- Browse event categories such as Academic, Technical, Cultural, Sports, and Career
- Open event details
- Event registration flow
- Manage my registered events
- Organiser side: create and update event status
- Event search and refresh support

### 4.4 Club Management
- Discover clubs
- Browse club details
- Join club requests
- Review pending requests
- Approve or reject join requests
- Club-based organisation management

### 4.5 Notice System
- Notice feed/home screen
- Notice search and filtering
- Notice detail page
- Create, edit, and delete notice support
- Notice API integration
- Display of college-level announcements and activities

### 4.6 Request Review Flow
- Clubs can receive student requests
- Request list with categories and filters
- Accept or decline requests
- Pending request count overview

### 4.7 App Navigation and UX
- Bottom navigation bar
- Screen routing through a centralized app route system
- Modern dark theme interface
- Smooth page transitions
- Responsive layout for mobile use

### 4.8 Data and API Support
- REST API communication through Dio
- Shared preferences/local storage
- Provider state management
- Structured models and repositories

## 5. What the Application Outputs
The app produces the following outputs for users:
- Updated event information and schedules
- Club discoverability and join approval management
- Instant notice communication for students
- Student and organiser profile information in one place
- A clean and organised campus activity dashboard
- A digital system for campus participation and engagement

## 6. Target Users
- College students
- Club leaders and organisers
- Department/event coordinators
- College administration

## 7. Technology Used
- Flutter
- Dart
- Provider for state management
- Dio for API calls
- Shared Preferences for local storage
- Material Design UI

## 8. Summary of Project Value
This project is valuable because it brings all key campus communication activities into a single app. Instead of relying on scattered messages and manual processes, the app creates a digital campus ecosystem that is faster, cleaner, and more organised.

In short:
- It saves time
- It improves communication
- It makes event participation easier
- It helps clubs and students connect faster
- It centralises campus updates and requests

## 9. Final Conclusion
The College Campus Engagement App is a practical digital solution for modern campus life. It helps solve communication, participation, and management problems in one system. The app makes student engagement more efficient and gives organisers a better way to manage events, clubs, and notices.
